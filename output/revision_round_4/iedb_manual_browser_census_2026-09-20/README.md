# IEDB manual public-browser census

All 98 frozen candidate arms were evaluated through 35 exact-peptide searches in IEDB's public browser interface. The browser interface was available even though the prior Query API retrieval failed.

One arm, HP47 EBV (BALF5 627-641, `TGGVYHFVKKHVHES`) at HLA-DRB1*15:01, has a positive exact-sequence/exact-allele MHC binding record (IEDB assay 1774674). Exact-HLA T-cell-only records are retained separately and do not satisfy the locked MHC/ligand criterion. No-hit searches remain non-penalizing: they are not evidence of absence.
